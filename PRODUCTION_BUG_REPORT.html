BUG-F31 Missing VITE_* environment variables crash the entire app at startup with no error message shown to user
File frontend/src/utils/env.js (requiredEnv) + frontend/.env (production values)
Impact App Launch Failure Payment Blocked If any required env variable is absent in the production build (e.g., VITE_API_URL, VITE_RAZORPAY_KEY_ID, VITE_PACKAGING_WEIGHT_KG), requiredEnv() throws at module load time. The entire app fails to render and the user sees a blank white screen with no explanation. This is especially dangerous in CI/CD pipelines where env vars might not be injected.
Required Vars The following must be set before production build or the app will not start:
VITE_API_URL # backend base URL VITE_RAZORPAY_KEY_ID # Razorpay public key VITE_PACKAGING_WEIGHT_KG # used in shipping calc VITE_COD_MAX_AMOUNT # COD order limit VITE_PREPAID_DISCOUNT_AMOUNT VITE_COD_FEE_AMOUNT VITE_PLATFORM_FEE_AMOUNT VITE_EMAIL_OTP_LENGTH
Root Cause requiredEnv() and numberEnv() are called at module level (outside components), so they throw synchronously before React mounts. No ErrorBoundary can catch this — the app simply does not render.
// Called at module level in Checkout.jsx, ProductDetail.jsx, etc.: const PACKAGING_WEIGHT_KG = numberEnv("VITE_PACKAGING_WEIGHT_KG"); // throws if missing
Fix — 3 steps
Step 1: Create frontend/.env.production with all required values filled in before deploying.

Step 2: Add a pre-build validation script that checks all required vars exist:
// scripts/check-env.js — run as part of npm run build const required = [ "VITE_API_URL", "VITE_RAZORPAY_KEY_ID", "VITE_PACKAGING_WEIGHT_KG", "VITE_COD_MAX_AMOUNT", "VITE_PREPAID_DISCOUNT_AMOUNT", "VITE_COD_FEE_AMOUNT", "VITE_PLATFORM_FEE_AMOUNT", "VITE_EMAIL_OTP_LENGTH" ]; const missing = required.filter(k => !process.env[k]); if (missing.length) { console.error("Missing env vars:", missing.join(", ")); process.exit(1); // fail the build, don't deploy broken app }
Step 3: Add the check to package.json:
"build": "node scripts/check-env.js && vite build"
